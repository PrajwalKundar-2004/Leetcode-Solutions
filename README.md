## 💡 About The Repository

This repository serves as a personal log of my journey through **Data Structures and Algorithms**. It contains my solutions to various **LeetCode** challenges and general algorithmic problems, aimed at improving problem-solving skills and coding proficiency.

## 📂 Project Structure

The repository contains solutions implemented in both **Java** and **JavaScript**.

- ☕ **`src/`** — All Java solutions (e.g., `TwoSum.java`, `MergeSortedArray.java`)
- 🟨 **`/` (Root)** — All JavaScript solutions (e.g., `TwoSum.js`, `ContainsDuplicate.js`)

## 🧠 Topics Covered

Solutions here span across a variety of crucial algorithmic concepts:

| Category | Description |
| :--- | :--- |
| **Arrays & Strings** | Manipulation, Two Pointers, Sliding Window |
| **Linked Lists** | Reversal, Merging, Cycle Detection |
| **Math & Bit Manipulation** | XOR operations, Number Theory |
| **Searching & Sorting** | Binary Search, Merge Sort, Quick Sort |
| **Dynamic Programming** | Memoization, Tabulation |

- **Clean Code:** Solutions are written with readability and clean coding practices in mind.
